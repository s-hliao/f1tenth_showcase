## Problem

Monocular depth estimation is up-to-scale — the projection matrix is non-invertible so absolute metric depth cannot be recovered from a single image alone. We recover scale by fitting an affine model to one image row where we have sparse but precise metric GT depth (RealSense or LiDAR).

---

## Pipeline

```
RGB frame
    │
    ▼
[DepthAnythingV2 ViT-S]
    │  D_disp(u,v)  — relative disparity (higher = CLOSER)
    ▼
[Anchor Row Selection]
    │  Auto-select row with max GT depth spread within max_gt_depth (3 m)
    │  OR use fixed --anchor-row R
    ▼
[Affine Scale Fit + RANSAC]
    │  D_metric = s·D_disp + t   (s < 0, since disparity is inverse depth)
    │  RANSAC: refit on inliers with relative error < 30%
    │  Guard: skip frame if |s| < 0.01 (degenerate)
    ▼
[Metric Depth Map]
    D_metric(u,v) = clip(s·D_disp + t, 0, max_depth)
```

**LiDAR path (Phase 2, not yet integrated):**
- Project `/scan` beams to image coords using K + T_lc
- `s_i = d_lidar_i / D_disp(u_i, v_i)` per beam
- RANSAC over `{s_i}` → single global scale `s`

---

## Key Math

- **Affine model:** `D_metric = s·D_disp + t` — s < 0 because DAv2 disparity is inverse depth
- **RANSAC inlier test:** `|s·D_disp(u_i,v_i) + t − d_gt_i| / d_gt_i < rel_tol`
- **Evaluation metrics:** AbsRel = mean(|D_pred − D_gt| / D_gt), MAE, RMSE
- **GT cap:** evaluate only pixels where `0 < d_gt ≤ max_gt_depth` (RealSense unreliable past ~3 m)

## CLI Reference

### `metric_depth.py` (offline)

```
--data-dir DIR        Root dir with rgb/, depth/, rel_depth/. Default: cwd.
--max-gt-depth M      Cap RealSense GT at M m. Output → output_<M>m/. Default: no cap.
--anchor-row R        Fix anchor to row R. Omit → auto-select per frame.
--frame N             Process only frame_NNNNN. Default: all frames.
--no-viz              Skip saving panels and profile plots.
```

### `depth_fusion_node.py` (ROS2 params, pass via `--ros-args -p key:=value`)

```
anchor_row     int    -1     -1 = auto-select per frame. ≥0 = fixed row.
max_gt_depth   float  3.0    Ignore RealSense GT beyond this (m).
max_depth      float  20.0   Clip predicted depth at this value (m).
inlier_rel_tol float  0.30   Relative error threshold for RANSAC inlier test.
display_vmax   float  0.0    Colormap max in m (0 = auto from GT 95th pct).
cam_width      int    848
cam_height     int    480
cam_fps        int    30
```

## Notes for Future Claude Sessions

- Yu-An Su: comfortable with Python, ROS2, CV/ML. Prefer targeted edits over rewrites.
- DAv2 outputs **disparity** (higher = closer) — the affine slope `s` is **negative**. Do not invert before fitting.
- RealSense GT in `testing_data/depth/*.npy` is float32 **metres**. ~20% of pixels are zero (invalid).
- RealSense is unreliable beyond ~3 m — always use `--max-gt-depth 3.0` for fair evaluation.
- Auto anchor row selection is in `best_anchor_row()` (metric_depth.py) and `_best_anchor_row()` (node). Both pick the row with the largest `max(GT) − min(GT)` among pixels with `0 < GT ≤ max_gt_depth` and ≥ 20 valid pixels.
- LiDAR integration (Phase 2) requires camera intrinsics K and extrinsic T_lc — not yet available.
- `conda env: vision_lab_v2` has torch+CUDA, timm, pyrealsense2, rclpy.
